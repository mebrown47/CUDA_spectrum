## Examples

Real-world applications demonstrating the drill-down workflow — one capture,

### (examples/)
RF workflow: full-band overview → carrier identification
→ modulation characterization → TDMA timing confirmation. Worked example using
a 430–440 MHz interference capture, identifying a TETRA base station at
431.350 MHz from spectral structure alone.

Scripts: `spectrum_plot.py`, `extract_power_envelope.py`, `find_periodicity.py`
